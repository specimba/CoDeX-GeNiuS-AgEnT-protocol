## Benchmark Context

Agent is **developer, not player**. Not asked to maximize score in pre-existing game, defeat opponents, solve fixed challenge, or act as evaluator. Any gameplay after development exists only to verify created game functions and communicates intended experience.

Primary question: Can agent independently create complete, creative, technically competent, visually compelling game that human judges would choose over competing entries?

See README.md for full benchmark design: code quality, creative originality, long-session execution, design judgment, visual ambition heavily weighted (beyond simple box gradient colored enemies / flash-game), human-perceived quality.
